# 体检报告解读 Agent 输入契约

## 0. 用途
本文件规定：要让 agent 生成一份合格体检报告解读，调用方必须提供什么、最好提供什么、缺失时如何处理，以及多份报告如何结构化。

本文件不是给最终用户看的，不进入最终报告。

## 1. 必需输入

| 字段 | 说明 | 缺失后果 |
|---|---|---|
| 年龄 | 精确到岁 | 无法准确做风险分层和参考范围判断 |
| 性别 | 男/女 | 无法判断女性专项、贫血、血脂等差异 |
| 体检报告原文 | 单份或多份 | 无法生成有效解读 |
| 报告日期 | 每份报告的具体日期 | 无法做趋势和复查间隔判断 |
| 异常项结构化 | 项目、结果、单位、参考范围、箭头 | 无法分层和阈值化建议 |
| 影像/心电图/超声原文 | 描述和结论 | 结节、斑块、脂肪肝等关键信息会丢失 |
| 医生结论/建议 | 报告中的结论和建议 | 无法判断机构已提示什么、漏了什么 |
| 用户目标 | 想看全面性、趋势、风险、复查建议等 | 报告侧重点可能不符合预期 |

## 2. 重要输入

| 类别 | 字段 |
|---|---|
| 职业/工作 | 久坐、倒班、粉尘、噪音、化学暴露、体力劳动、高压 |
| 既往病史 | 高血压、糖尿病、血脂异常、脂肪肝、甲状腺、肿瘤等 |
| 家族史 | 早发心血管病、糖尿病、肿瘤等 |
| 用药 | 降压药、降糖药、降脂药、抗凝药、激素、保健品 |
| 生活方式 | 烟、酒、运动、饮食、睡眠、体重变化 |
| 女性专项 | 月经、生育、绝经、HPV/TCT、乳腺检查 |
| 当前症状 | 胸痛、气短、头晕、便血、体重下降等 |
| 历年报告 | 至少 2—3 年，用于趋势和漏项分析 |

## 3. 可选输入

- 体检机构名称、检测方法。
- 身高、体重、腰围、BMI、血压。
- 既往手术史、过敏史。
- 近期急性疾病、熬夜、饮酒、剧烈运动等临时因素。
- 用户特别关心的问题。
