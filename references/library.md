> 本文件是**清单与用法**，不是内容。库本体约 **317MB / 334 个文件**，因体积与
> 再分发约束**不随包发布**；规格、界值、间隔一律回到原始文件读取，
> ⛔ 不得凭记忆作答（见 `SKILL.md` §各国资料入口）。

## 一、为什么不在包里

1. **体积**：300MB+ 超过任何技能包/注册表的上限（多数渠道 ≤50MB）。
2. **再分发**：库内多为各国官方文件（卫健委、厚生劳动省、USPSTF、NICE、WHO…），
   再分发需逐个确认许可；更稳妥的做法是"给来源，让使用者自行获取官方原件"。
3. **与运行无关**：解读主链路（抽取→归一→判定→组合→结论→对账）**不依赖**该库；
   库只在"回答某国/某机构的口径问题"时按需读取（SKILL.md 的问答纪律）。

## 三、怎么用（`CHECKUP_LIB`）

```bash
export CHECKUP_LIB="/path/to/体检推荐指引文件"       # 指向你自备的库
# 之后按 SKILL.md §各国资料入口 的表格按需读取原文；
# 回答必须带出处（指南全称 + 年份 + 章节）+ 声明"不可与本次中国口径混用"
```

**库不可达时**（未设置 `/ 路径错 / 文件缺失）：
如实回答"**资料不在本机**"，并说明可从对应官方渠道自备；
⛔ 不得凭记忆作答，⛔ 不得编造出处。

## 四、如何自行获取（**随包索引** + 渠道原则）

📇 **获取索引随包**：[`references/library-index/`](library-index/README.md) ——
10 个分目录索引（文件名 / 机构 / 发布日期 / 官方 URL，共 342 条）+ 机器可读
`manifest.json`，另记有"未能下载的条目"。**按索引逐条下载即可，不必重新检索**：

1. 打开 `references/library-index/manifest.json`（或分目录 `.md`）；
2. 按 URL 到官方站点下载原件，按索引里的文件名归档；
3. `export CHECKUP_LIB=<你归档的目录>` 即可使用。

> 索引只有链接与元数据（不含文件本体，故可自由传播）；文件再分发需各自确认站点条款。

其余原则（索引未覆盖的新文件按此处理）：

1. 优先**发布机构官网**（卫健委、厚生劳动省、MHLW、MOH、USPSTF、NICE、WHO…的
   "指南/标准/告示"栏目），下载 **PDF/DOCX 原件**（不要二手转载页）。
2. 保存时保留**原始文件名 + 年份**；必要时同时保存发布日期页面截图作为出处凭证。
3. 按本文件第二节的目录结构归档，并在目录内维护一份 `links.md`
   （文件 → 来源 URL → 采集日期 → 校验方式）。
4. 校验可读性：PDF 用 `PyMuPDF` 打开、DOCX 用 `zipfile` 打开，确认无 HTML 错误页混入。

## 五、已知缺口（如实）

- **归一化锚点标准**（如 `WS/T 886-2026` 一类"项目名→编码"的权威锚点）**不在库中**：
  项目名归一目前靠引擎自建的 208+ 条词典 + 登记制映射（`engine/catalog/analytes.json`）。
- **台湾**资料未获取；新加坡部分为 2010–2017 历史版（`links.md` 有标注）。
- 库内**不含 OCR 通道**；扫描件仍不在支持范围（见 README 支持矩阵）。
