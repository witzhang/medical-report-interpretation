## 二、六条纪律（全部有机制在盯）

1. **出处纪律**：指南必须写**全称 + 年份**（"《中国血脂管理指南（2023 年）》"）；
   `quote_verbatim` 是**逐字原文、不是摘要**；说不出年份就写"以最新版为准，请复核"。
2. **核实状态纪律**：`verified` 只填**实际核到原文的**；核不到 → `false` + 写明原因
   （**有测试锁死，不许伪装**）。
3. **版本纪律**：多版本**并列展示**，禁止静默择一（代谢综合征×3、HbA1c 2020 vs 2024、
   血脂 21 格表的适用人群）；版本差异进报告时**显式标注**。
4. **口径纪律**：**中国口径优先**（他国只作对照，且必须声明"**不可与本次中国口径混用**"）；
   干预前水平规则；eGFR 等报告值规则；"红"≠ 官方危急值。
5. **登记纪律**：指南阈值、生理常数、就医成本与时长**先登记再引用**（逐条带出处）。
6. **缺口纪律**：机制在数据缺的（分层参考区间表空）、人群不匹配的（CVi 是欧洲人群）、
   拿不到原文的（付费墙、未收集地区）——**如实标注，不装知道**；
   受影响的结论标"证据等级不足"。**库不可达时如实说"资料不在本机"，⛔ 不得凭记忆作答**。

## 三、新知识进库五步

```
找到原文 → 登记（constants.json / 规则库 provenance，带出处与 locator）
        → 标核实状态（verified: true/false + 原因）
        → 引用（报告/规则里用登记过的数；⛔ 不引用未登记的数）
        → 对账（数字追踪能指回；开放项双向对账不含孤项）
```

## 四、国际口径问答（P3）

- 报告里**不出现**国际对照章（已撤销的设计，勿再实现）。
- 用户问某国口径时：**现读该国原文**回答（入口见 SKILL.md「各国资料入口」），
  带出处（指南全称 + 年份 + 章节）+ 声明**"不可与本次中国口径混用"**。
- 某国被问 ≥3 次才考虑结构化进 `rules/criteria_<国>.json`；⛔ **不预先结构化**。
