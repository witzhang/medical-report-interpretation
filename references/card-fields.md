# 问题卡片字段规格（12 项；名称固定，不许改名）

> 出处：v6.3 两份实例的卡片结构。**卡片必须自足**：看完一张卡就知道
> "这是什么、要不要紧、接下来做什么、什么情况必须马上就医"；⛔ 不依赖其它章节。

| 字段 | 必填性 | 内容要求 | 来源 |
|---|---|---|---|
| **结果** | 必填 | 数值链 + 单位 + 参考范围（含各年区间差异） | 脚本（`facts.json`/`states.json`） |
| **白话解释** | 必填 | 用日常话讲这是什么；⛔ 零内部术语（"噪声阈值"→"它平时的正常起伏"） | agent |
| **趋势** | N≥2 必填 | 数值链 + 方向 + 一句定性；**必须点出"机构当时怎么说"**；机构曾把已进入指南过渡地带的项写成"正常"时**显式指出** | 脚本供数，agent 写 |
| **可能原因与个人关联** | 条件 | 与画像（吸烟/饮酒/家族史/体重）挂钩；无个人关联可省 | agent |
| **最坏会怎样** | 必填 | 给读者的风险上界与安心面；⛔ 不恐吓、不空慰 | agent |
| **要吃药吗** | 必填 | 结论 + "是否用药由 XX 科医生决定" | agent（判据来自 `rules/`） |
| **严重度** | 必填 | 级别 + 一句话为什么是这个级别（**必须对照 `states.json` 的「报告级别/级别判据」**；若与产物建议不一致，必须写 `（调档：<理由>）`——理由要能指回底稿或问诊；对账 S10 会核） | agent |
| **目标** | 条件 | 可量化的目标值（带单位，如 TG <1.7 mmol/L） | 脚本/规则库 |
| **现在做什么** | 条件 | 可执行动作（含具体量：每周 150 分钟、限盐 <5 g/日…） | agent |
| **复查** | 必填 | 五要素行（见下） | 脚本供数 + agent 写 |
| **如果暂时不复查** | 条件 | 最低限度的替代动作 + 升级条件 | agent |
| **⚠️ 立即就医** | 按适用 | 该问题**特有的**急症信号；数据类问题（如好胆固醇）无此项，改"提前就诊"句亦可 | agent |

## 展示顺序（以两份 v6.3 实例为准）

结果 → 白话解释 → [专属说明，如"这一项为什么特殊""为什么值得单列"] → [趋势] →
[可能原因与个人关联] → 最坏会怎样 → 要吃药吗 → 严重度 → [目标] → [现在做什么] →
复查 → [如果暂时不复查] / [⚠️ 立即就医]（末两者顺序可互换，都在卡片末尾）。

**允许**在标准字段之外插一个"专属于这张卡"的说明项（当卡片入选理由不自明时）——
实例中"这一项为什么特殊""为什么单独列出来""为什么四项要放一起看"都是这种。

## 「复查」行格式（五要素，实例逐字）

```
- **复查**｜⏱ <时间窗> · 🏥 <科室> · 💰 <费用>（各地不同，以医院为准）· ⏳ <耗时与要不要请假> · 📋 <准备事项>
```

⏱🏥💰 必填；⏳（请假问题）与 📋（准备/空腹/带什么）按适用——无请假问题或无需准备时可省。

## 卡片硬规则

- **同一件事只占一张卡片**（"脂肪肝 / 肝回声增强 / 肝酶升高"是一件事）。
- **影像类发现的尺寸必须标注检查方式**（彩超/CT/骨密度）；**不同方式的发现不得互相推断**（对账 S05/S06）。
- **数据类卡片**（如好胆固醇同值）必须写清"这不是身体问题，是数据问题"，措辞锁"**无法核实**"（对账 G06）；
  ⛔ 不指控机构。
- 级别 emoji 必须与第 4 节级别定义、`states.json` 的「报告级别」一致（**含影像台账**；
  若报告调档，必须在「严重度」里写明 `（调档：<理由>）`）。
- **问诊结果若改变了级别**（如家庭血压 <130/80 → 血压项降 🟢），同样要在「严重度」里写
  `（调档：依据问诊——家庭血压 7 天平均 X）`——**问来的事实也要可对账**。
- 目标值、阈值、频率一律**来自 `rules/` 或底稿**，⛔ agent 不凭记忆写频率/阈值。
- ⛔ 不给诊断、药名、剂量；涉药写"是否用药由 XX 科医生决定"。
