## 三、技术说明

- **访问限制**：nice.org.uk 对非浏览器客户端全站返回 HTTP 403（nginx 层拦截，含 PDF 资源路径，curl 与自定义请求头均无法通过）。本次改为通过**真实浏览器上下文**在站内发起同源 `fetch()` 取回 PDF 字节流后落盘，因此文件与浏览器直接下载所得一致。
- 全部文件已校验：`%PDF` 文件头、体积 > 2KB、页数正常（20–177 页，与各指南公开篇幅一致）。
- 文件名为「首次发布年份」；各指南的实际版本以表中「最近更新」列为准（NICE 官网 PDF 始终为最新版）。
