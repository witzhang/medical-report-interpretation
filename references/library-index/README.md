# 指引文件库：**获取索引**（不含内容）

> 这里放的是"**哪份文件、来自哪个官方链接、什么发布机构/文号**"的采集记录 ——
> 目的是让后来者**不必重复检索**。本目录**不含任何原文内容**（正文见各官方链接）。

## 怎么用

1. 看 `manifest.json`（机器可读，342 条）或对应目录的 `<目录名>.md`（人读表格）。
2. 按链接到官方站点下载原件；按 `<目录名>.md` 里的**原始文件名**归档
   （保留机构前缀与年份，便于日后核对版本）。
3. 收集完把库放在任意位置，用环境变量指过去：
   ```bash
   export CHECKUP_LIB="/path/to/体检推荐指引文件"
   # 之后技能会按 SKILL.md §各国资料入口 按需读原文（带出处回答）
   ```
4. 若某项链接失效：**按"机构 + 文号/发布日期 + 标题"重新检索**（索引里的
   `org`/`date` 两列就是给这个用的线索），并回填到你的副本里。

## 许可与再分发（重要）

- 本目录只有**链接与元数据**（文件名/机构/日期/URL），不含文件本体 ——
  链接是公开信息，可自由传播。
- **文件本体不在包内**：各国政府文件的使用条款不一，若要**镜像/再分发**文件，
  请自行确认各站点条款；索引只负责"指路"。
- 索引是**采集时点**的快照（2026-10 初），政府站点改版频繁，失效属正常。

## 维护（欢迎补条目）

- 新增/修正条目：改对应 `<目录名>.md` 并同步 `manifest.json`（字段：
  `dir/file/org/date/url`），保持与库内文件名一致。
- 建议附"采集方式与校验"（如 `curl` + `file` 校验、PDF/DOCX 能打开、>1KB），
  以便他人复现；缺什么也可写进"未能下载的条目"一节。

> 本索引的**定位**：把一位使用者已经做过的"检索+下载"劳动变成公共资产，
> 让下一个人的起点不是零。它**不承诺权威全集**，只承诺"我采到过什么、从哪采的"。
