# 数据准确性机制（四张底稿 · 对账器 · 边界）

> **一句话**：报告里每一处事实性判断（数字 / 缺或有的判断 / 状态分类 / 机构建议摘录）
> 都由脚本产出，并被对账器逐条核对。agent 不再看 CSV 手工数。
> 完整说明见 `<skill>/reconcile/README.md`；本节是执行摘要。

## 一、三层对账

1. **编号检查（checks）**：每条断言 = 一个可执行检查；期望值来自四张底稿或
   `constants.json`；检查**同时扫报告与两张图的 spec**（图里的文字也是报告的一部分）。
   四组：**C** 覆盖/缺口 · **S** 状态/影像 · **I** 机构建议 · **G** 通则。
2. **数字追踪**：报告里每个"数值+单位"都要能指回某张底稿；
   匹配口径 = 产物值**按报告自己的显示精度四舍五入** 且 **单位可比**
   （μ/µ≡u、％≡%、大小写宽容；**跨单位的数值巧合不算指回**——如 `24.0%`
   不得指回 `GGT 24.0 U/L`）；多行候选取**最强匹配**（精确 > 精度内 > 0.5% 容差）。
   指不回的进「需人工确认」清单 → 人工确认后二选一：**补进底稿** 或
   **登记常量**（`--constants` / `CHECKUP_CONSTANTS` / 数据根
   `constants.user.json`，附加为「用户登记」，逐条带出处）。
3. **人工确认台账**：引擎确实给不出的陈述显式登记，报告必须带"需人工确认"措辞。

## 二、四张底稿（`artifacts/<名>/`）

| 底稿 | 回答什么 | 谁在用 |
|---|---|---|
| `coverage.json` | 缺口表与覆盖率（对照卫健委 2025 版基本体检项目，逐项 × 逐年） | 附录一（整节） |
| `states.json` | 跨年状态分类（位置轴/变化轴/官方分带）、影像台账（发现 × **检查方式** × 逐年） | 章二每项表述、卡片「趋势」栏 |
| `advice.json` | 机构建议摘录（主检条目 + **分科小结**，逐条带页码）+ 主题抽取（复查频率/措辞标记） | 全篇涉及机构建议处 |
| `facts.json` | 数值事实表（每个被引用的数值/派生量/数据质量发现） | **数字追踪与断言检查的唯一来源** |

## 三、边界（执行时逐条遵守）

1. 数字追踪**只覆盖带单位的数值型陈述**；解释性/建议性文字不在追踪范围。
   目标是全部指回，但**不以数字凑指标**：确无脚本出处的数值（agent 手算/单位换算）
   如实进「需人工确认」，并在报告里写清算式与来源。
2. **指南阈值与就医成本/时长不是观测数据** → 登记在 `constants.json`（逐条带出处）；
   **改价/改期限先改登记**，否则对账会列为"需人工确认"。
3. 两件**只能人工确认**的事（措辞锁「**无法核实**」，不指控机构）：
   ① 某项三年同值是否重测过；② 某项大幅变化是否换过检测方法。
   解开路径：复查一次 / 向机构书面确认 → 作为新证据补进底稿 → 重跑对账 → 结论更新。
4. **覆盖率语义**（定义在机制层，不在 agent 脑子里）：
   - **全覆盖** = 全部必查子项在**每一次**体检都有记录；
   - **部分覆盖** = 缺年份 / 子项被拒查 / 子项门槛型整块缺失（三种原因，⛔ 不可混为一谈）；
   - **缺** = 所有年份都没有记录；**覆盖率** = 全覆盖项数 ÷ 应查项数（四舍五入整数百分比）；
   - ⛔ "缺"与"报告未载明"是两件事；**做过不得写缺、没做必须写缺**（双向锁）。
5. **影像类发现必须标注检查方式**；不同方式的发现**不得互相推断**（同句出现必须消歧）。
6. **同一条事实，全篇必须同步**（数值/措辞强度一致，由对账器锁）。

## 四、定稿门槛

- **报告定稿 = 对账全绿（退出码 0）+ 未追踪数字逐条有交代**（尽量为 0；确为
  agent 手算/换算的须在报告写明算式与来源）+ `validate_report.py` 结构回归通过
  + 抽样回读无「断链」（回读完成度如实计入——无页码的派生/百分比不计入分母）。
  不通过就不许交付（硬规矩）。
- 加一个新案例：换机构 → 引擎三件套 → `gen_artifacts --engine-out` → `reconcile --artifacts`；
  **checks 是产物驱动的，换案例不用改检查代码**（见 `reconcile/README.md` 命令 A）。
- 交付物四件套（同目录）：`<报告>.md` + `<同名>_merge_diagram.svg` +
  `<同名>_causal_graph.svg` + 对账记录（`对账_<名>.md`）。
