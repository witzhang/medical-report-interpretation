## 零、v6.4 三条硬增量（逐字要求）

**1. 目录**（位置：版本行之后、`## 一、总体评估` 之前；只到节级）

```
## 目录

- 一、总体评估：1. 健康状况总览 · 2. 综合判断 · 3. 正常与改善项 · 4. 问题分级总览 · 5. 行动建议
- 二、逐项分析：6. 需尽快就诊的项（🔴）· 7. 需干预或定期复查的项（🟡）· 8. 年度复查即可的项（🟢）
- 附录一：检查项目完整性评估 · 附录二：数值对照表 · 免责声明
```

**2. §4 问题分级总览改版**——**每个级别一张表**，开头给数量：

```
> 级别含义：🔴 … ｜ 🟡 … ｜ 🟢 … ｜ ⚪ …

**各级数量**：🔴 0 项 ｜ 🟡 7 项 ｜ 🟢 5 项 ｜ ⚪ 3 项

**🔴 已达诊断或前期标准，需尽快就诊（0 项）**
本次没有红色项——没有一项达到需要尽快就诊的档位。

**🟡 需要干预或定期复查（7 项）**
| 项目 | 现在的情况 | 这意味着什么 |
|---|---|---|
| … | … | … |

（🟢 / ⚪ 同式；**空的级别也要出现**并写明"本次 0 项"）
```
数量口径：**报告里该级别下列出的条目数**（允许一项一行、也允许同类合并成一行，但要与表里的行数一致）。

**3. §5 行动建议：五类"单一归属"**——⛔ 同一件事**只出现在一类**里：

- **③（自己在家）**承载"**先自测/先记录，达到某条线再去医院**"的事项——**触发线与期限写在 ③ 行内**（"7 天平均 ≥135/85 → 心内科"）。
- **①（需要尽快去医院）只列"已经确定要去"的事**（如专科评估、复查核实）——
  ⛔ **不再把"还需先自测才能决策"的对象（如血压）列进 ①**；确需在 ① 出现时，
  必须写成"带 <记录> 就诊"并**从 ③ 撤下**（二选一，不许两处并存）。
- ② = 可以等下次体检一起做；④ = 吃药与保健品；⑤ = 生活习惯（⛔ 不重复 ①–④ 已列的动作）。
  ⚠️ 反例（首测实测）：① 写"家庭血压记录 7 天后就诊｜2 周内就诊"、③ 又写"血压｜7 天平均 ≥135/85 → 心内科"——
  **一个无条件、一个有条件，读者不知道听谁的**。对账 **S12** 专抓这一类。

   ★ 前提假设声明：<年龄> · <性别> · <用不用药> · <有无诊断> · <吸烟> · <家族史>

   版本行：**v6.4** 及本版改动摘要（目录 · 分级分表与数量 · 行动五类单一归属）

## 一、总体评估

   4. 问题分级总览   （表：级别 / 项目 / 现在的情况 / 这意味着什么）
   5. 行动建议       （按「该怎么办」分五类）

## 二、逐项分析       （按级别分节，节名与第 4 节的级别定义一致）
   6. 需尽快就诊的项（🔴）
   7. 需干预或定期复查的项（🟡）
   8. 年度复查即可的项（🟢）

## 附录一：检查项目完整性评估   （数据 = coverage.json；只评估、不给行动）
## 附录二：数值对照表           （含「原报告页」列；N≥5 截断）

**章二的分节规则**：只列 🔴/🟡/🟢 三级；**⚪（未评估）不单独成节**——在第 4 节
表里以 ⚪ 行出现，并写明"是'不知道'，不是'没问题'"。**空的级别不出现，但章首必须
一句话说明哪个级别是空的**（例："本次没有红色项（无「需尽快就诊」这一节），所以从黄色开始"）。
节号**连续**（缺级别不占号）；同一件事只占一张卡片。

## 二、标题规范（四条规则，照抄实例）

1. 不绑定单次体检（报告可能覆盖 1–5 年）；
2. 不用操作指引式的话（如"先看两张图"）；
3. 不用口语与内部代号（如"做得好""红黄绿"）；
4. 同一层级的风格统一。

补充纪律：⛔ 不用口号式/指引式标题；⛔ 不用临时提示语当标题（要提示就用正文加粗句）；
章标题用内容名（"总体评估""逐项分析"）；节标题用**读者会说的话**；
⛔ 不许三层编号（本形态是两章 + 连续编号 1–8）。
卡片标题格式：`#### <级别emoji>【颜色】<问题名> —— <一句话状态>`。

## 三、各节硬要求

**1. 健康状况总览**：两张图按顺序（先归类、后关联），**都在第 1 节**；
每张图下必须配"看什么"；因果图下必须配"三个共同导致的关键答案"式文字结论；
图区必须带两句声明（①同框是**合并**起来看的推断、**不是诊断**；②"不知道的"一栏表示"没查"，不是"没问题"）。

**2. 综合判断**：第一句就是好消息（有据可依的安心）；把多个异常**归成一个上游**
（"六项是一件事"）；给时间观与**一个抓手**（"只打算做一件事就做这件"）；
⛔ 不放 A/B 类声明（属第 4 节）；⛔ 不作分析详述（详述在卡片）。

**3. 正常与改善项**：逐条列好消息，**每条带数值**；必须包含"数据连续"本身
（"你三年做了 3 次体检，数据连续——正是因为有这条线才能看到下面那些轨道"）；
若某条好消息带前提（如 eGFR 上升来自肌酐下降），**就地写明问号**并指向对应卡片。
⛔ 好消息不许埋在详述中间（本节必须早于问题卡片）。

**4. 问题分级总览**：表 `级别 | 项目 | 现在的情况 | 这意味着什么`；
表前写级别含义（逐字）：🔴 **已达诊断或前期标准，需尽快就诊** ｜ 🟡 **需要干预或定期复查**
｜ 🟢 **正常或轻微** ｜ ⚪ **未评估**（是"不知道"，不是"没问题"）。

**级别的判据（解耦后，v6.4）**——级别回答"**你现在要不要为它做什么**"，**不是**"机构让多久查一次"：

- 🟢 = **现在不需要你做什么**：按既有节奏复查即可（含机构给的每半年——**频率只进「复查」行**）；稳定、或曾长过又稳住、或首见且很小。
- 🟡 = **需要你现在动手**（去查实、去复查确认、去改）**或**复查比常规年度更密**且有具体风险信号**
  （增长超出测量误差 / 分级升高未回落 / 机构建议的进一步检查未执行 / 高危背景＋记录断档且形态需盯）。
- ⛔ **两条硬禁令**：① **机构主动给出的复查频率（如「每半年」）本身不构成升级理由**——
  那是机构的风控节奏，不等于"你现在有事"；② **级别必须与脚本产物一致**（`states.json` 的
  `项目状态[*].报告级别` / `影像台账[*].报告级别`）；确有必要调档时，必须在卡片「严重度」里写
  `（调档：<理由>）`，理由要能指回底稿或问诊（对账 S10 会核）。

**影像条目格式（图与正文通用）**：`<发现名>（<检查方式>）+ 数值/状态`——
**检查方式必填**（彩超 / CT / 骨密度 / 心电图…），不同方式不得互相推断（对账 S05/S05b/S06）。
⚠️ **A/B 类声明必须存在**：本报告的"红"**不等于**官方 A/B 类危急值
（血压 ≥180/110 伴急性症状、ALT ≥15 倍上限、肌酐 ≥707 μmol/L；ALT 5～15 倍属 B 类）——
那是机构**紧急召回**口径；本报告分级是给**个人健康管理**用的，更细、更早。
若本次无红色项，表后必须写"本次没有红色项"＋"但有一件必须尽快去做的"。

**5. 行动建议**：按「该怎么办」分五类：

```
① 需要尽快去医院的（有时间要求，别拖）      ← 表：做什么 / 多久内 / 去哪 / 花费与时间
② 可以等下次体检一起做的（不急，但别漏）    ← 表：做什么 / 为什么排在这里
③ 自己在家观察和记录的（不花钱，自己就能做）← 表：观察什么 / 怎么做 / 出现什么情况要去医院
④ 吃药和保健品                              ← 结论式段落（没有就写"目前都不需要"）
⑤ 生活习惯要改的（自己就能做，回报最大）    ← 表：改什么 / 具体怎么做
```
- ①**按临床重要性排、不是按时间排**，并写明"这几件都要做，不必二选一"
  （全篇**排序声明只此一处**，对账 G09 锁）。
- ⛔ **单一归属（v6.4）**：同一件事只进一类——尤其是"先自测按线决定"的（归 ③）；见"零、v6.4 三条硬增量"。
- ⑤ 的"戒烟/减重"必须给**可执行细节**（包年数怎么算、依赖怎么判断、戒烟日/替代动作、减重分几步），
  ⛔ 不写"戒烟"两个字了事。
- ④ 必须含服药安全提示句（对账 G08 硬性检查）："**如果你已经在服用任何药物（降压、降糖、降脂等），
  本节不适用**——本报告是在「未服 XX 药」的前提下写的。**切勿自行停药或改药**。"⛔ 本类不给药名、不给剂量。

**附录一**（§2.5）：章首声明"本节只做评估，不给行动"；对照依据（卫健委 2025 版基本体检项目）
+ 适用（年龄/性别）；覆盖率四列小表；缺口明细（"它本来能发现什么 + 为什么值得知道"）；
部分覆盖逐项给原因（缺年份 / 子项被拒查 / 子项门槛）；超出指引的加分项；
另一个扣分项（断档年 or 项目常年不变）；怎么读 + 一句好消息。
数据**全部来自 `coverage.json`**；⛔ 不含因异常加做的项目（归卡片）；⛔ "缺"与"报告未载明"不混。

**附录二**（§2.6）：列 `项目 | 单位 | 参考范围 | <各年值…> | 原报告页`；
参考范围用**最后一次**机构标注的范围并注明各年可能不同；N=1 只有一列；
**N≥5 保留首次 + 最近三次，中间省略并注明**；缺失留空白（⛔ 不是"正常"）；
换算格标 `ᵐ`。数据来自 `facts.json` 数值表 + 影像台账 + 页码。

## 四、读数前的声明（章二开头，实例逐字有）

- 采样间隔不均等（由脚本按实际日期算，⛔ 不写死文案）；
- 数据质量项（如身高跨年极差 → BMI 打折；文件名≠内页日期）；
- 缺失年份的说明（"那年不是'没问题'，是'没查'"）。
- 通用急症信号列表 + "各问题自己特有的急症信号写在卡片末尾"。
- 排序原则：先可逆的、再不可逆的；先时间紧的、再可以等的；同一件事只占一张卡片。
