# 多年对比独有禁令（**N≥2 个体检日期时必须读**）

> 读这一份的时机：脚本报出 **≥2 个体检日期** 时——在写任何"趋势"字样之前。
> 单份报告（N=1）**没有**趋势概念，读完下面「N=1」一节即可。

## 一、总禁令（重灾区，逐条硬性）

1. ⛔ **缺失不进均值、不进图、不进任何统计**；⛔ 不插值、不凭空连线。
2. ⛔ **缺口不是"没问题"，是"不知道"**——缺失三分语义必须区分：
   `[未做]`（该查没查）/ `[未找到]`（做了但资料没有）/ 确实为 `0`。
3. ⛔ **不可比 → 断线**：单位不可比、跨机构口径变化 → 只报位置，
   标"**本次为新基线**"，⛔ 不写"升高/降低"。
4. ⛔ **参考区间变更必须标注**（"变高"可能只是区间换了；判断当年是否超标看当年报告）。
5. ⛔ **趋势结论不许 agent 自己看 CSV 数出来**，必须来自脚本输出（`states.json`）。
6. ⛔ **影像尺寸只在同一种检查方式内比较**（彩超 ≠ CT ≠ 骨密度）；
   一个结节**只和它自己比**；换方式/换层厚/换机构 → "本次为新基线"。
7. ⛔ 3–5 个数据点**禁止跑回归**（R² 几乎由点数决定）。
8. **两轴分开讲**：位置轴（超没超**当年各自的**区间）与变化轴（是否超出平时的正常起伏
   ——RCV 噪声阈值）**不合并成一句**；`取决于CVi取值` 的项不能当确定结论用。
9. **顺序**：先判噪声轴、再判余量轴（否则会把"位置正常但真的在变"的项误标成临界）。

## 二、N 年适配（N = 1 到 5+）

| N | 允许说什么 | 禁止说什么 | 结构上要做的调整 |
|---|---|---|---|
| **1** | 位置（超没超）、距临界线余量 | ⛔ **任何趋势词**（升高/降低/恶化/改善） | ①「趋势」栏统一写"**首次检测，无历史对比**"；② 主图只画横断分组、不画方向；③ 因果图只到"发现→上游"两层；④ **显式声明"本次只回答位置，不回答方向"**；⑤ 附录一缺口表按单列 |
| **2** | "与上次相比"（两两比较） | ⛔ "趋势""持续上升" | 数值串 2 点 |
| **3–4** | 完整趋势 | — | 现状不变 |
| **≥5** | 完整趋势 + 阶段性表述（"前三年…近两年…"） | ⛔ 数值串超过 5 个点 | 数值串截断：**首点 + 最近三点 + "…"**，注明"中间 N 次省略"；总览表超 ~12 行时分三组（长期异常 / 近年新发 / 曾异常已回落） |

## 三、趋势句怎么写

- 公式 = **数值链 + 方向 + 一句定性**；
  - 反例："转氨酶 92→71→118，均偏高"（只报数，没有定性）；
  - 正例：带上"机构当时怎么说"（见下条）。
- **必须点出"机构当时怎么说"**；机构曾把已进入指南过渡地带的项写成"正常"时，
  **显式指出**（实例：机构只写「正常血压」而不给区间，按现行标准该读数可能已在正常高值段）。
- **「曾异常已回落」必须写明回落**，并说明"回落是否可信"（是结构性信息，不是常规）。
- **同一年复查**（短期、看干预响应）与**多年演变**（长期、看慢病进展）
  两种口径**不混在同一段话里**。
- 采样间隔不均等 → **方向性提醒**由脚本按实际日期算（间隔越长越容易漏判），
  ⛔ 不许写死文案。RCV 阈值不随间隔变；变的是敏感度。

## 四、「临界上升」判据（三级优先，脚本实现，agent 不参与）

1. **官方分带**（强）：血压正常高值/重点关注段、空腹血糖与 HbA1c 前期、血脂四项边缘升高……
2. **eGFR 斜率**（强）：自然下降 0.4～1.0/年；KDIGO「快速进展」>5/年（判紧急度）。
3. **兜底**（弱，引用必须标注）：a) 方向一致且距上限 <10%；b) 距上限 <5%（贴线）。
   ⚠️ 入选时必须标注"**该项临界带无权威依据，仅供参考**"。

判据编码在引擎（P1-A0 并入后），报告层直接引用引擎/底稿产物，⛔ 不在报告里重算。
